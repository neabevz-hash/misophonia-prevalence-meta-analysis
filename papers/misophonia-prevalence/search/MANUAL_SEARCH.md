# Ручной поиск (делает автор, после регистрации на OSF)

Google Scholar закрыт для бота капчей, поэтому его проходит человек — в обычном браузере, ничего ставить не нужно. BASE и OATD не открываются ни у Claude, ни у автора; вместо них Claude ищет по OpenAIRE и CORE через их API — это агрегаторы тех же репозиториев (протокол, §9).

Файлы кладите в папку `papers/misophonia-prevalence/search/runs/<дата финального поиска>/manual/` — дату я назову, когда запущу финальный поиск. Запишите дату поиска и число результатов, которое показала программа: это идёт в PRISMA-S.

## 1. Google Scholar — в обычном браузере, без установки

Ссылки на все 20 страниц — в `search/SCHOLAR_PAGES.md`: 2 запроса × 10 страниц по 20 результатов.
Откройте ссылку → `Ctrl+S` → сохраните в папку `manual/` под именем из таблицы. Если Google покажет капчу, пройдите её и сохраните страницу с результатами.

## 2. LILACS через BVS (по желанию, одна попытка)

Поисковые серверы BVS (`pesquisa.bvsalud.org`, `search.bvsalud.org`) сбрасывают соединение из нашей сети, а API требует ключ.
1. Откройте https://pesquisa.bvsalud.org/portal/ через мобильный интернет (раздача с телефона).
2. Если открылось: строка `misofonia OR misophonia OR misofonía`, все базы → *Exportar* → RIS (или CSV) → файл `bvs_export.ris`.
3. Если нет — напишите «BVS не открылся». Тогда LILACS отдельно не ищем: SciELO и OpenAlex частично покрывают его журналы, в статье это будет названо ограничением.
