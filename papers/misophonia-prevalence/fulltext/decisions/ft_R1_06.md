**Как размечать.** Откройте полный текст (ссылка в блоке), сверьте предложение ИИ и допишите код в строку **Решение:**.

| Код | Что значит |
| --- | --- |
| `=` | согласен с ИИ |
| `+` | подходит: есть число людей с мизофонией и знаменатель в выборке, набранной не из-за мизофонии |
| `-1` | не подходит: обзор, комментарий, клинический случай, качественное или теоретическое |
| `-2` | не подходит: выборка набрана из-за мизофонии или чувствительности к звукам |
| `-3` | не подходит: нет инструмента именно для мизофонии |
| `-4` | не подходит: нет числа случаев со знаменателем (только средние, корреляции) |
| `-5` | не подходит: не про мизофонию |
| `-6` | не подходит: та же выборка, что в другом отчёте (связать) |
| `-7` | не подходит: другое — напишите почему |
| `?` | пока не решил (до закрытия файла нужно решить) |

Цифры в таблице случаев ИИ брал из текста, но выписываться они будут на следующем этапе по оригиналу — здесь решаем только «подходит / нет» и причину.
