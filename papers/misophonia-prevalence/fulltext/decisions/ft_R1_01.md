| Код | Что значит |
| --- | --- |
| `=` | согласен с ИИ |

| `-1` | не подходит: обзор, комментарий, клинический случай, качественное или теоретическое |

| `-3` | не подходит: нет инструмента именно для мизофонии |
| `-4` | не подходит: нет числа случаев со знаменателем (только средние, корреляции) |
| `-5` | не подходит: не про мизофонию |
| `-6` | не подходит: та же выборка, что в другом отчёте (связать) |
| `-7` | не подходит: другое — напишите почему |
| `?` | пока не решил (до закрытия файла нужно решить) |
